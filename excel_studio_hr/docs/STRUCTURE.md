## Структура данных (data/)

```
%LOCALAPPDATA%\ExcelStudioHR\
├── settings.json          # Настройки приложения
├── users.json             # Пользователи и роли
├── references.json        # Справочники
├── state/                 # Состояние job, маркеры выполнения
├── warehouse/             # SQLite хранилище истории
│   └── warehouse.db
├── backups/               # Автосохранения
├── logs/                  # Журналы
│   ├── app.log
│   └── crash.log
├── updates/
│   └── rollback/          # Точки отката обновлений
├── migrations/            # Миграции схемы данных
├── sandbox/               # Песочница тестового контура
├── legal/                 # Документы оснований ПДн
└── plugins/               # Сторонние плагины
```

## Профиль развёртывания: без прав администратора

Все пути - только в профиле пользователя:
- Установка: `%LOCALAPPDATA%\Programs\ExcelStudioHR\`
- Данные: `%LOCALAPPDATA%\ExcelStudioHR\`
- Реестр: только HKCU
- Автозапуск: Run-ключ HKCU или задача ONLOGON уровня пользователя
- IPC: per-user named pipe `\\.\pipe\ExcelStudioHR-{SID}`
