## Этап 1: MVP (базовый цикл)

Реализованы ключевые модули Этапа 1:
- **М1**: Загрузка xlsx/xlsm/xls/CSV, ленивая загрузка стилей (FR-0103)
- **М2**: Постраничный просмотр (2000 строк), undo/redo, поиск, фильтры
- **М4**: 15 операций с op_id, цепочки, сериализация JSON
- **М9**: Стек, JOIN, агрегация, дедупликация
- **М15**: Экспорт Excel/CSV/JSON, версионирование, BI-формат

### Тесты пройдены
```
✓ М1: модель листа создана
✓ М2: просмотр, поиск, редактирование, undo/redo
✓ М4: выполнение цепочки операций
✓ М9: слияние стек, дедуп, агрегация
✓ М15: экспорт в форматы
```

## Профиль развёртывания: без прав администратора

Все пути - только в профиле пользователя:
- Установка: `%LOCALAPPDATA%\Programs\ExcelStudioHR\`
- Данные: `%LOCALAPPDATA%\ExcelStudioHR\`
- Реестр: только HKCU
- Автозапуск: Run-ключ HKCU или задача ONLOGON уровня пользователя
- IPC: per-user named pipe `\\.\pipe\ExcelStudioHR-{SID}`
