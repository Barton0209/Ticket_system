# Excel Studio HR v3.2.1
## Автоматизированная станция обработки кадровой отчётности
### Профиль развёртывания: без прав администратора

Desktop-приложение для Windows, обеспечивающее полный цикл работы с кадровыми Excel/CSV-отчётами от обособленных площадок (ОП).

## Структура проекта

```
excel_studio_hr/
├── src/                          # Исходный код приложения
│   ├── core/                     # Ядро: модель листа, движок операций
│   ├── modules/                  # 41 модуль системы (М1–М41)
│   ├── ui/                       # Интерфейс PySide6
│   └── utils/                    # Утилиты
├── data/                         # Данные приложения (%LOCALAPPDATA%\ExcelStudioHR\)
│   ├── state/                    # Состояние job, маркеры выполнения
│   ├── warehouse/                # SQLite хранилище истории
│   ├── backups/                  # Автосохранения
│   ├── logs/                     # Журналы
│   ├── updates/rollback/         # Точки отката обновлений
│   ├── migrations/               # Миграции схемы данных
│   ├── sandbox/                  # Песочница тестового контура
│   ├── legal/                    # Документы оснований ПДн
│   └── plugins/                  # Сторонние плагины
├── tests/                        # Тесты и фикстуры
├── docs/                         # Документация
├── legal/                        # Лицензии, оффер исходников
├── requirements.txt              # Зависимости
├── setup.py                      # Установка pip
├── build_exe.py                  # Сборка PyInstaller
└── README.md                     # Этот файл
```

## Быстрый старт

### Вариант 1: Установка без прав администратора (рекомендуется)

```bash
pip install --user -r requirements.txt
python -m src.main
```

### Вариант 2: Portable-режим

```bash
# Распаковать папку в любое место профиля пользователя
# Запустить main.py или excel_studio_hr.exe
python src/main.py
```

### Вариант 3: Inno Setup установщик

```bash
# После сборки: ExcelStudioHR-Setup.exe
# Устанавливает в %LOCALAPPDATA%\Programs\ExcelStudioHR\
# Без прав администратора (PrivilegesRequired=lowest)
```

## Зависимости

**Обязательные:**
- Python 3.10–3.12
- PySide6 ≥ 6.6 (LGPL-3.0)
- openpyxl

**Опциональные (мягкая деградация):**
- pandas, numpy — массовые операции
- charset-normalizer, xlrd — CSV/старые .xls
- oletools — чтение VBA
- xlwings + Excel — исполнение VBA
- pywin32 + Outlook — почта
- reportlab — PDF
- pyzipper — шифрование пакетов
- python-docx — Word
- qrcode — QR-коды
- requests — ИИ-API
- torch + transformers — локальный ИИ (не в EXE)

## Роли пользователей

| Роль | Права |
|------|-------|
| **Оператор ОК** | Запуск шаблонов, просмотр/правка, экспорт; применение маппингов |
| **Аналитик** | + сценарии, маппинги, валидация, compliance-профили, diff |
| **Администратор** | + справочники, VBA-библиотека, конфигурация, каналы ПДн, роли |

## Ключевые возможности

1. **Приём файлов**: Outlook, папки, буфер обмена
2. **Распознавание структуры**: авто-маппинг по отпечатку структуры
3. **Контроль качества**: DQ-скор, валидация, sanity-чеки
4. **Юридический compliance**: медосмотры, удостоверения, ПДн 152-ФЗ
5. **Сведение по ОП**: стек с контролем полноты
6. **Хранение истории**: SQLite warehouse, тренды 36 мес.
7. **Документы**: Excel/PDF/Word/QR/1С:ЗУП
8. **Дисциплина ОП**: квитанции, рейтинг, календарь, эскалация
9. **Автоматика**: расписание, headless job, таймер
10. **Безопасность**: роли, PIN, маскирование ПДн, каналы выгрузки
